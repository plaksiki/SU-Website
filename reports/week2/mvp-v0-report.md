## Purpose and description of the MVP v0 foundation

Purpose of the MVP v0 is to have an openable link for all users and to develop primarely style, design. Th v0 MVP shall address US-01 and US-02 user stories: open an event page to find all relevant details and participate in SU events, find general information about the Student Union on the main page to understand what SU does and how it is organized.

MVP v0 has both main page with general info about SU and its departments and also link to events (+ events page). Design of this version is based on customers feedback.
