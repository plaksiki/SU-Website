## Feedback & Requested Changes

### UX/UI Issues

- Non-intuitive question addition in surveys — the current mechanism does not meet user expectations
- Lack of seamlessness — forced page reloads are required to display new data
- Suboptimal screen space usage and "massive scrolling" on the event creation page

### Functional Gaps

- Need to implement survey response statistics (optional)
- Issues with data export — currently all files are downloaded at once
- No ability to edit created events (only deletion is available)
