## Reference UI
Google AI Studio was used to generate a reference React+TypeScript UI prototype of the SU Portal. It served as a visual reference for design and layout decisions. The actual implementation was developed independently by the team.

## General Assessment
As first-year students with limited prior development experience, AI tools were occasionally consulted for clarification, debugging support, and documentation assistance. All architectural decisions, code implementation, and design choices were made by the team independently. AI tools helped accelerate routine tasks such as formatting, template generation, syntax lookup, and transcript processing, while core product decisions remained team-driven.
