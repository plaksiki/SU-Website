## Reference UI
Google AI Studio was used to generate a reference React+TypeScript
UI prototype of the SU Portal. It served as a visual reference
for design and layout decisions. The actual implementation
was developed independently by the team.

## General Assessment
As first-year students with limited prior development experience,
AI tools were occasionally consulted for clarification and
debugging support. All architectural decisions, code implementation,
and design choices were made by the team independently.
